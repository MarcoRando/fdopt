# Experiments

Here we report the instructions to reproduce the experiments of the paper "A Structured Tour of Optimization with Finite Differences"


## Computational cost

In "sampling_cost" folder, run the script "sampling_cost.py" with the desired number of repetitions and indicating the path where the results should be saved.
```bash
python sampling_cost.py <reps> <path_to_save>
```
The script will generate a file "cost_generating_matrices.csv" in the specified path. To plot the results, run the script "plot_cost.py" with the path to the file generated by the previous script.
```bash
python plot_cost.py <path_to_file>
```

## Gradient approximation error

In "estimator_quality" folder, run the script "estimator_quality.py". The script estimator_quality.py evaluates the accuracy of gradient estimators on synthetic functions.

```bash
python3 estimator_quality.py fun_name d [--optional_args]
```

Arguments

fun_name (str): Name of the function to test.

d (int): Dimensionality of the input space.

Optional Arguments

--L (float): Smoothness parameter (default: 10000.0)

--mu (float): Strong convexity (default: 1.0)

--n (int): Sample size for logistic regression (default: 1000)

--lam (float): Regularization for logistic (default: 1e-5)

--out_dir (str): Output directory (default: './')

--reps (int): Repetitions for averaging (default: 50)

--h (float): Finite difference step size (default: 1e-7)

Example: compute gradient approximation error for least squares function with Lipschitz constant 10000.0 and strong convexity parameter 1.0 using h = 1e-7.
```bash
python3 estimator_quality.py least_squares 500 --L 10000.0 --mu 1.0 --out_dir ./results
```

Then results can be plotted with the script "plot_synthetic_results.py".

Example

```bash
python3 plot_synthetic_results.py least_squares 500 ./results 1e-7 10000 1
```

Function names are "least_squares", "logistic", "trid", "quing", "rosenbrock", "griewank".

To run the experiments on CUTEst problems, run the script "estimator_quality_cutest.py".

Example
```bash
python3 estimator_quality_cutest.py --out_dir ./results
``` 

Arguments

--out_dir (str): Output directory (default: './')

--reps (int): Repetitions  (default: 50)

--h (float): Finite difference step size (default: 1e-7)

Then results can be plotted with the script "plot_cutest_results.py".

Example
```bash
python3 plot_cutest_results.py ./results/grad_approx_error/ffd/cutest/
```

## Convergence

To run the experiments on convergence, run the script "convergence.py". 

Example 

```bash
python3 convergence.py least_squares 500 --L 10000 --mu 1.0 --T 10000 --out_dir ./results --reps 10
```

Arguments

fun_name (str): Name of the function to test.

d (int): Dimensionality of the input space.

--L (float): Smoothness parameter (default: 10000.0)

--mu (float): Strong convexity (default: 1.0)

--T (int): Number of function evaluations (default: 10000)

--out_dir (str): Output directory (default: './')

--reps (int): Repetitions for averaging (default: 50)

--h (float): Finite difference discretization parameter (default: 1e-7)


Function names are "least_squares", "logistic", "trid", "quing", "rosenbrock", "griewank".

Then results can be plotted with the script "plot_conv.py".

Example
```bash
python3 plot_conv.py least_squares 500 10 ./results 10000 1 1e-7 
```

To run the experiments on CUTEst problems, run the script "convergence_cutest.py".

Example
```bash
python3 convergence_cutest.py --out_dir ./results
``` 

Arguments


--out_dir (str): Output directory (default: './')

--reps (int): Repetitions  (default: 50)

--h (float): Finite difference step size (default: 1e-7)

Then results can be plotted with the script "plot_cutest_results.py".

Example
```bash
python3 plot_cutest_results.py ./results/grad_approx_error/ffd/cutest/
```

## Adversarial

To run the experiments on adversarial examples, run the script "adv_exp.py".

Example
```bash
python3 adv_exp.py ./results 10 'qr'
```

Arguments

out_dir (str): Output directory (default: './')

reps (int): Repetitions  (default: 50)

method (str): Direction generator (e.g. 'qr', 'householder', 'coordinate', 'butterfly', 'permuted_householder', 'spherical', 'gaussian', 'rademacher')

Then results can be plotted with the script "plot_results.py". To plot the results you need to run the script "adv_exp.py" first for every direction generator.

Example
```bash
python3 plot_results.py ./results 10
``` 

Classifier can be trained with the script "train_classifier.py" (pretrained model is available in "./models/mnist/student").
